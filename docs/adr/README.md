# Architecture Decision Records

ADRs capture durable technical decisions for ClawMox.

## Status model
- Proposed
- Accepted
- Deprecated
- Superseded
- Rejected

## Naming convention
Use zero-padded numeric prefixes:
- `0001-api-first-control-plane.md`
- `0002-docker-runner-for-infra-jobs.md`

## Current ADRs
- [0001 API-first control plane](./0001-api-first-control-plane.md)
- [0002 Docker runner for infra jobs](./0002-docker-runner-for-infra-jobs.md)
- [0003 No arbitrary shell from chat](./0003-no-arbitrary-shell-from-chat.md)

## ADR template
Use this structure:
- Title
- Status
- Context
- Decision
- Consequences
- Alternatives considered
